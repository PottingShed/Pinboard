Chrome
Settings → On start-up → Open a specific page → paste the link. For the home button too: Settings → Appearance → Show home button.
Safari
Settings → General → paste the link into Homepage, then set New windows and New tabs to open with Homepage.
Firefox
Settings → Home → Homepage and new windows → Custom URLs → paste the link. Do the same for New tabs.
Edge
Settings → Start, home and new tabs → Open these pages → add the link.
